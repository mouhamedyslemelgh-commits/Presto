# PRESTO — Pilotage des livreurs

Application Next.js 16, TypeScript et React, inspirée de la maquette PRESTO. Fonctionnalités : tableau de bord, registre, distribution équipements, Mobile Money, recherche, filtre, édition et export CSV. **Démonstration uniquement.** Données fictives dans localStorage : aucune authentification, aucune base de données. Ne saisissez pas de données personnelles réelles. Pour exploiter en production, ajouter authentification, rôles, stockage sécurisé et sauvegardes.

```bash
npm install
npm run build
npm run dev
```

Déployez sur Vercel en important le dépôt GitHub Presto (répertoire racine, Framework Next.js).
